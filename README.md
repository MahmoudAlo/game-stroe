🎮 Game Store

A modern and responsive gaming store website designed for gamers to explore trending games, discover popular titles, and shop for digital gaming products.

The project aims to provide a simple and enjoyable shopping experience for gamers, including digital game cards, gaming subscriptions, and online memberships.

🌟 Features
Modern Homepage: Attractive landing page with a welcoming introduction.
Navigation Bar: Easy navigation between different website sections.
Search Bar: Search interface for finding games.
Trending Games: Display of currently popular games.
Most Played Games: Showcase of popular gaming titles.
Top Categories: Browse games by category.
Interactive UI: Hover effects and smooth transitions.
Responsive Layout: Designed with flexible CSS layouts.
🛒 Store Products

The store is designed to offer digital gaming products such as:

Digital Game Cards.
Gaming Gift Cards.
Gaming Subscriptions.
Digital Memberships.
Online Gaming Products.
🛠️ Technologies Used
HTML5 – Structuring the website.
CSS3 – Styling, layouts, hover effects, and transitions.
Google Fonts – Using the Roboto font family.
Flexbox – Creating flexible and organized layouts.
